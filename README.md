## ขั้นตอนติดตั้ง (สำหรับผู้ที่ยังไม่เคยใช้)

### 1) สร้างโปรเจกต์ Supabase

1. ไปที่ https://supabase.com → สมัคร/เข้าสู่ระบบ → **New project**
2. ตั้งชื่อโปรเจกต์ + ตั้งรหัสผ่านฐานข้อมูล (จดไว้) → รอสร้างเสร็จ ~2 นาที
3. เมนูซ้าย **SQL Editor** → **New query** → คัดลอกเนื้อหาทั้งหมดจากไฟล์
   [`supabase/schema.sql`](supabase/schema.sql) มาวาง → กด **Run**
   - จะสร้างตารางทั้งหมด, สิทธิ์ (RLS), ที่เก็บโลโก้ และบัญชีผู้ดูแล `admin` / `044357246`
4. เมนู **Project Settings → API** จดค่า 3 อย่าง:
   - `Project URL`
   - `anon public` key
   - `service_role` key (ความลับ! ห้ามเปิดเผย)

> หมายเหตุ: บัญชีผู้ใช้ใช้ “อีเมลสังเคราะห์” เช่น `admin@grade.local` โดยอัตโนมัติ
> ผู้ใช้พิมพ์แค่ชื่อผู้ใช้ (`admin`) ระบบต่อ `@grade.local` ให้เอง
> (ค่านี้ตั้งได้ที่ตัวแปร `NEXT_PUBLIC_LOGIN_DOMAIN` ต้องตรงกับที่ใช้ใน schema — ค่าเริ่มต้นคือ `grade.local`)

### 2) รันในเครื่อง (ทดสอบ)

```bash
npm install
```

คัดลอก `.env.local.example` เป็น `.env.local` แล้วใส่ค่าจากข้อ 1:

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=xxxx
SUPABASE_SERVICE_ROLE_KEY=xxxx
NEXT_PUBLIC_LOGIN_DOMAIN=grade.local
```

แล้วรัน:

```bash
npm run dev
```

เปิด http://localhost:3000 → เข้าสู่ระบบด้วย `admin` / `044357246`

### 3) Deploy ขึ้น Vercel

1. Push โค้ดขึ้น GitHub (ดูด้านล่าง)
2. ไปที่ https://vercel.com → **Add New → Project** → เลือก repo นี้
3. หน้า **Environment Variables** ใส่ค่า 4 ตัวเดียวกับ `.env.local`
4. กด **Deploy** — เสร็จแล้วจะได้ URL ใช้งานจริง

> อย่าลืมเพิ่ม URL ของ Vercel ใน Supabase → **Authentication → URL Configuration**
> (Site URL / Redirect URLs) หากต้องการ แต่สำหรับการล็อกอินด้วยรหัสผ่านแบบนี้ไม่จำเป็น

## การใช้งานครั้งแรก

1. เข้าสู่ระบบด้วย `admin` / `044357246` → **เปลี่ยนรหัสผ่าน admin** (ผ่านเมนูจัดการครู → รีเซ็ตรหัส) เพื่อความปลอดภัย
2. ไปที่ **ข้อมูลโรงเรียน** → กรอกข้อมูล + อัปโหลดโลโก้ + ตรวจเกณฑ์ตัดเกรด
3. ไปที่ **จัดการครู** → เพิ่มครูประจำชั้น
4. ไปที่ **ห้องเรียน** → สร้างห้อง (ติ๊ก “เติมรายวิชา…อัตโนมัติ”) → มอบหมายครูประจำชั้น
5. เปิดห้อง → เพิ่ม **นักเรียน** → **กรอกคะแนน** → พิมพ์ **รายงาน/PDF**

## หมายเหตุด้านความปลอดภัย

- `service_role` key มีสิทธิ์เต็ม — ใช้เฉพาะฝั่งเซิร์ฟเวอร์ (ตั้งใน Environment Variables เท่านั้น ห้าม commit)
- ระบบใช้ Row Level Security (RLS): ครูเห็น/แก้ได้เฉพาะห้องของตนเอง, ผู้ดูแลระบบเข้าถึงได้ทั้งหมด

## อัปเดตเฟส 2 (เทียบโอน + PDF เต็มหน้า + แก้ผลลัพธ์)

**ผู้ที่เคยรัน `schema.sql` ไปแล้ว** ให้รันไฟล์ [`supabase/schema_v2.sql`](supabase/schema_v2.sql)
เพิ่มเติมใน SQL Editor (ปลอดภัยต่อการรันซ้ำ) — เพิ่มช่อง override เกรด และตารางระบบเทียบโอน
(ติดตั้งใหม่ทั้งหมดผ่าน `schema.sql` มีของเฟส 2 อยู่แล้ว ไม่ต้องรัน v2 ซ้ำ)

สิ่งที่เพิ่ม:
- 🔄 **เทียบโอน** — แท็บใหม่ในห้องเรียน: จับคู่ “วิชาหลักสูตรใหม่ (ต้นทาง)” → “วิชาโครงสร้างเดิม (ปลายทาง)”
  รวมหลายวิชาเป็น 1 ได้ ระบบดึงคะแนนรายปีมาเฉลี่ยและตัดเกรดให้อัตโนมัติ
- 🖨️ **PDF เต็มหน้า A4** ตามแบบ ปพ.5 จริง — รายงานรายคนเลือก **ภาคเรียนที่ 1 / 2 / รายปี** และแบบ **เทียบโอน**
- ✍️ **แก้ผลลัพธ์** — override เกรดรายวิชาต่อคนได้ (คอลัมน์ “แก้เกรด” ในหน้ากรอกคะแนน; เว้นว่าง = ใช้ค่าที่ระบบคำนวณ)
- 📐 เกณฑ์ระดับคุณภาพปรับให้ตรงระเบียบ (ผ่าน ≥ 1.0, ดี ≥ 1.5, ดีเยี่ยม ≥ 2.5)

## อัปเดตเฟส 3 (นำเข้านักเรียน + โครงสร้างหลักสูตร)

**ผู้ที่มีฐานข้อมูลเดิม** ให้รันไฟล์ [`supabase/schema_v3.sql`](supabase/schema_v3.sql)
ใน SQL Editor หนึ่งครั้ง เพื่อเพิ่มหัวข้อสมรรถนะผู้เรียนให้ห้องเรียนเดิม (ไฟล์รันซ้ำได้)

สิ่งที่เพิ่ม:
- 📥 นำเข้ารายชื่อนักเรียนจาก CSV พร้อมตรวจข้อมูลซ้ำ และดาวน์โหลดไฟล์ตัวอย่างได้จากหน้ารายชื่อนักเรียน
- 📚 หน้าบันทึกรายวิชาหลักสูตรใหม่ 2568 และหน้ารายวิชาเทียบโอนหลักสูตร 2560
- 🎯 หน้าบันทึกสมรรถนะผู้เรียน 6 ด้าน แยกภาคเรียนที่ 1 และ 2
- 🌱 ปรับชื่อหน้ากิจกรรมพัฒนาผู้เรียนและคุณลักษณะอันพึงประสงค์ให้ชัดเจน

หัวคอลัมน์ CSV ที่รองรับ:

```csv
เลขที่,เลขประจำตัว,เลขบัตรประชาชน,คำนำหน้า,ชื่อ,นามสกุล,เพศ,วันเกิด,หมู่เลือด,สถานะ
```

รองรับไฟล์ UTF-8 และ Windows-874 รวมทั้งตัวคั่น comma, semicolon และ tab
